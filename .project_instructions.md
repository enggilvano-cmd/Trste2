## BDI Calc Pro — Decisões de Projeto

### Paleta de cores (PlaniFlow)
- Primary (azul): `#176EB5` / HSL `207 77% 40%`
- Primary glow: `#1D89E2` / HSL `207 77% 50%`
- Accent/Warning (laranja): `#E2863C` / HSL `27 74% 56%`
- Success (verde): `#16A249` / HSL `142 76% 36%`
- Destructive: `#EF4343`
- Content background: `#EDF2F7`
- Login background: `#1469B6`
- Border: `#E1E7EF`

### Padrão visual
- `.financial-card` com gradient-card, backdrop-blur, shadow-card, hover translateY(-1px)
- Sidebar recolhível (72px / 256px), item ativo com gradient `from-primary to-primary-glow` + bolinha branca
- Tipografia: família sistema Apple (-apple-system, SF Pro Display, Segoe UI, Roboto)
- `--radius: 0.75rem`

### Estrutura
- Navegação por estado `currentPage` no componente raiz (SPA-like, sem rotas internas)
- Páginas: Dashboard, Calculadora, Histórico, Referência TCU, Configurações (admin)
- Autenticação: e-mail + senha, cadastro aberto, papéis admin/user
- Banco: User, BdiCalculation, SystemSetting (defaults de BDI configuráveis pelo admin)

### Regras de negócio BDI
- Fórmula TCU Acórdão 2622/2013
- Tipos de obra com limites Q1/Médio/Q3
- Desoneração conforme Lei 14.973/2024 (2025–2027)
- Exportação PDF via HTML2PDF API

### Idioma
- Toda interface em português (pt-BR)
